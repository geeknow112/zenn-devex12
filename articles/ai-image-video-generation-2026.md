## 画像生成ツール比較

### 1. Midjourney

**特徴：**
- アート・イラスト系に強い
- Discord経由での操作
- V6でフォトリアル品質が向上

**料金（2026年6月時点）：**
| プラン | 月額 | GPU時間 |
|-------|------|---------|
| Basic | $10 | 3.3時間 |
| Standard | $30 | 15時間 |
| Pro | $60 | 30時間 |

**実務での使いどころ：**
- ブログ・記事のアイキャッチ画像
- プレゼン資料のイメージ素材
- コンセプトアート・ラフ案

**プロンプト例：**
```
Japanese tech blog header image, 
clean modern design, 
blue gradient background, 
minimalist style,
--ar 16:9 --v 6
```

### 2. DALL-E 3（ChatGPT Plus内蔵）

**特徴：**
- テキスト描画が正確
- ChatGPTとの対話で生成
- 著作権侵害対策が厳格

**料金：**
- ChatGPT Plus: $20/月（画像生成含む）
- API: $0.040/枚（1024x1024）

**実務での使いどころ：**
- テキスト入りバナー
- 図解・ダイアグラム風イラスト
- SNS投稿用画像

**強み：日本語テキストも比較的正確**
```
「AIで業務効率化」と書かれたビジネス向けバナー画像、
青と白を基調とした清潔感のあるデザイン
```

### 3. Stable Diffusion（ローカル実行）

**特徴：**
- 無料・オープンソース
- ローカルで実行可能
- カスタムモデル（LoRA等）が豊富

**必要スペック：**
- VRAM: 8GB以上（推奨12GB）
- ストレージ: モデル1つあたり2-6GB

**料金：**
- ソフトウェア: 無料
- GPU電気代: 月数百円程度

**実務での使いどころ：**
- 大量生成が必要な案件
- 特定スタイルの継続的な生成
- 機密性の高い素材（ローカル完結）

## 実際に使ってみた感想

### 良かった点

1. **時短効果が大きい**
   - フリー素材を探す時間 → ほぼゼロ
   - 自分のイメージ通りの素材が手に入る

2. **コスト削減**
   - ストック素材サービス不要
   - カメラマン・イラストレーター外注の削減

3. **ブランド統一感**
   - 同じプロンプトで一貫したスタイル
   - 後から追加生成しても統一できる

### 実際の試行錯誤エピソード

**技術ブログのアイキャッチ作成で学んだこと：**

最初は「プログラミングのイメージ画像」のような曖昧なプロンプトで生成していましたが、毎回テイストがバラバラでした。

試行錯誤の結果、以下のテンプレートに落ち着きました：

```
[テーマ] tech blog header,
clean modern design,
[メインカラー] gradient background,
minimalist flat illustration style,
no text,
--ar 16:9 --v 6
```

**ポイント：**
- `no text` を入れないと意味不明な文字が入る
- `minimalist flat illustration` で統一感が出る
- `--ar 16:9` でブログサムネイル用の比率を固定

この「自分用テンプレート」を作ってからは、1発で使える画像が出る確率が8割以上になりました。

### 注意点

1. **著作権・商用利用**
   - 各サービスの利用規約を確認
   - 生成物の権利帰属を把握

2. **品質のばらつき**
   - プロンプト調整に試行錯誤が必要
   - 100%の品質保証はない

3. **依存リスク**
   - サービス終了・料金改定のリスク
   - 重要素材はローカル保存
